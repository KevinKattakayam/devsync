## Manual review of incomplete items

- `aria-prohibited-attr`: labels on the generic Document tools and Selection formatting containers are not well supported without a role. These remain an explicit semantic follow-up. Their actual buttons have labels; do not count this incomplete item as resolved.
- `color-contrast` and `link-in-text-block`: reported overlap includes the shell Copilot, floating menu/bubble, helper copy and breadcrumb. Visible token pairs are covered by the existing contrast tests; the overlap itself remains an interaction/visual limitation. Clipped/offscreen text cannot be certified from these captures.
- `aria-hidden-focus`: the shared Radix dialog hides the background/focus guards. Escape is exercised, but a full Tab/Shift+Tab and assistive-technology review of every editor overlay is deferred. No rule was suppressed.
