`backend/docker/entrypoint.mjs` now calls a single read-only PostgreSQL query in `runtime-role-guard.mjs` before starting the API or worker. It fails closed for superuser, BYPASSRLS, CREATEDB, CREATEROLE or REPLICATION attributes; any direct role membership (a conservative restriction including benign memberships); effective database/schema CREATE; non-system relation, function or type ownership; and effective TRIGGER or TRUNCATE table privileges. The guard does not revoke grants, perform migrations, inspect every callable SECURITY DEFINER routine, prove all RLS policies or detect later privilege changes; audit these and temporary privileges independently. Managed services assigning mandatory role membership may require a separately reviewed solution rather than bypassing the guard.
