# Load and restore preflight — incomplete

The existing `tools/quality/load.js` is a k6 constant-10-VU, 30-second local REST read workload. It requires a fixture URL and private token and refuses nonlocal targets; its p50/p95 output is not evidence until an actual run is retained. No k6 or Artillery executable was found in this environment. No load run, capacity result, SLO attainment, or provider cost measurement is claimed.

`backend/src/observability/metrics.ts` exposes HTTP request counts and latency histograms, AI call/error counts, and per-instance collaboration connection/room gauges. These do not by themselves establish queue lag, Yjs update throughput, reconnection latency, database locks, or provider costs. The metrics endpoint requires a configured bearer token. Existing [realtime recovery evidence](../realtime-recovery/README.md) records a fixture-identity Chrome journey with three clients, 70 edits, compaction and application-server SIGKILL while PostgreSQL and Redis remained available. It is a correctness exercise, not a load benchmark or proof of provider integration.

`docs/RUNBOOK.md` describes backup and restore procedures and explicitly states that no dump/restore drill was run. `docker info --format '{{.ServerVersion}}'` reported permission denied accessing the Docker socket in this execution environment. No disposable database or Redis was started, no service was stopped, and no backup was restored. PostgreSQL restart, Redis outage, queue retry, network loss, copied-backup restore and record/CRDT comparison remain unverified in this phase.

To continue, use an isolated environment with an accessible container runtime, a pinned and recorded k6 version, disposable seeded identities and services. Record the environment, commands, thresholds, raw aggregate results and failures without recording credentials. Restore only a fixture backup into a fresh disposable target, then compare source and restored counts and decoded CRDT content. Define and verify actionable dashboard/alert thresholds against observed behavior. No production targets or production data are authorized by this preflight.
