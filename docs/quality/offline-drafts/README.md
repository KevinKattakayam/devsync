## Local draft export increment

The document page now offers an explicit unencrypted export after a checkbox acknowledgement. It snapshots the current Y.Doc, caps encoded updates at 8 MiB, includes format/version/account/room metadata, and uses a fixed filename without resource titles. A download request is not reported as a completed save. The detached inspection helper rejects accidental scope mismatches, malformed/oversized input and unsupported versions, without applying anything to the live document. File metadata is not cryptographic identity or authorization; no import/upload UI exists. Exported files may include private content and local actions and require private storage.
