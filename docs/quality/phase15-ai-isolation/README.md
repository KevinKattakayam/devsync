# Grounded AI connected-source isolation regression

The authenticated v3 grounded route calls `groundedPreview` with the authenticated actor. `groundedPreview` checks workspace authority, calls `searchKnowledge`, sends accessible excerpts to the configured provider, and reopens each source after provider I/O. `searchKnowledge` uses `withWorkspaceAccess` and a tenant transaction. Its SQL filters document rows by workspace and archive state; GitHub execution rows join repositories by workspace, require OWNER, and exclude disconnected repositories. Existing database integration tests cover foreign actors, archived documents, fabricated citations, and GitHub search visibility.

A new database integration regression exercises `groundedPreview` with matching local and foreign GitHub repositories, tests owner and viewer paths, and disconnects the local repository during the mocked provider call. The model gateway alone is mocked; workspace authorization, retrieval queries and post-provider source checks use the non-bypass runtime database client. Fixture records and provider responses do not demonstrate live GitHub or model access.
